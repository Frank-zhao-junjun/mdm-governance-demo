# 如何打开本目录下的 `.drawio` 文件

## 方式一：draw.io Desktop（离线，推荐）

官方发布页（含 **v29.6.1** 及 Windows / macOS / Linux 安装包）：

**[https://github.com/jgraph/drawio-desktop/releases/tag/v29.6.1](https://github.com/jgraph/drawio-desktop/releases/tag/v29.6.1)**

- Windows：选择 **Windows Installer** 或 **Windows No Installer (zip)**  
- 安装后：**文件 → 打开** → 选择 `Collibra_数据治理PoC_NotebookLM_PPT源稿.drawio`

## 方式二：在线 diagrams.net

打开 [https://app.diagrams.net](https://app.diagrams.net) → **Open Existing Diagram** → 选择本地 `.drawio` 文件。
