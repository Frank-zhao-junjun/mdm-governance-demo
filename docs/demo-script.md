# AI 增强型数据治理 Demo 演示剧本

## 演示目标

在 15 分钟内证明：系统以确定性规则守住治理底线，AI 仅提供可追溯建议；任何归并和数据修改均由责任人带着证据裁决。

## 演示前准备

1. 在 `backend/` 执行 `python scripts/seed_demo_data.py --reset`，生成固定种子的 5,000 条演示存量数据（默认量与 5,000 实体批次上限一致，可直接整表跑质量检测）。需要现场演示分批扫描时改用 `--records 10000`。
2. 启动后端与前端，使用 `data001 / datapass001` 登录。
3. 确认 Copilot 工作台、治理驾驶舱、Agent 活动流、权责冲突四个导航入口可访问。
4. 现场验证时准备 5-10 条客户物料。每条至少包含名称、物料类型、基本计量单位；记录缺失项或客户争议项。

## 15 分钟流程

| 时间 | 操作 | 讲解重点 | 验收点 |
|---|---|---|---|
| 0:00-2:00 | 打开“治理驾驶舱” | 质量分、重复率、待办数量和 Agent 活动来自实时治理数据，不是静态报表。 | S1、S3、S7 |
| 2:00-4:00 | 打开“Copilot 裁决” | 每张卡片同时显示证据链、风险标注和替代选项。系统推荐，不代替 Owner 决策。 | S3 |
| 4:00-6:00 | 展示 10 条增量或客户现场物料的标准校验结果 | 名称、属性、单位检查均为只读；每条问题至少生成修正建议或质量工单，不静默忽略。 | S2、AC-1、AC-12 |
| 6:00-8:00 | 展示质量工单及责任人 | 质量问题分配给 Steward，SLA 到期会升级；工单状态由人工裁决推进。 | AC-2、AC-7 |
| 8:00-10:00 | 展示 `10.9` 与 `8.8` 同规格螺栓归并候选 | 即使语义层建议归并，强度等级冲突属于 L1 规则，结论固定为“不建议合并”。 | S5、AC-3、AC-8 |
| 10:00-12:00 | 在归并卡片填写裁决意见、勾选二次确认后批准 | 未填写意见或未确认会被拒绝。批准只令工单进入执行预检，系统不自动修改主数据。 | S4、AC-4、AC-9 |
| 12:00-13:00 | 打开“权责冲突” | FA 同意、FB 反对的样例进入双方 Owner 会签和治理委员会裁决，保留争议上下文。 | AC-5 |
| 13:00-14:00 | 打开“Agent 活动流”或问责查询 | 任一裁决可回溯 Agent、模型版本、输入摘要、证据引用和审批前快照。 | S7、AC-11 |
| 14:00-15:00 | 回到驾驶舱并刷新 | 待办数和治理指标随裁决状态更新。总结“AI 建议可见、规则冲突可拦、人工责任可追”。 | S1、AC-10 |

## 现场验证判定

对客户提供的每一条陌生物料，在演示记录表中登记以下之一即视为闭环：

- 已生成带 L1/L2/L3 证据等级的修正建议。
- 已生成并指派质量工单。
- 已生成归并候选，或被 L1 冲突规则明确拦截。
- 已由 Owner 批准、驳回或改判，并保留审批证据快照。

若任何记录未命中既有规则，必须登记为人工复核或规则补充事项；不得声称“系统已自动识别”。现场目标是 0 条静默漏过，而非声称 100% 缺陷识别。

## 验收证据

| 指标 | 证据 |
|---|---|
| S1：流程 ≤15 分钟 | 本剧本分配总时长 15 分钟；现场以计时器记录。 |
| S2：5-10 条陌生数据闭环 | `tests/test_demo_e2e.py` 验证 10 条输入均有建议和质量工单；现场按上方记录表走查。 |
| S3：裁决三件套 | Copilot 页面固定渲染证据链、风险标注、替代选项。 |
| S4：未批准归并被拒 | API 合同测试验证 `POST /api/governance/merge-execute` 对未批准工单返回 `409`。 |
| S5：B 类强度拦截 | E2E 使用种子中的 `DM000001`（10.9）与 `DM000002`（8.8），断言 L1 返回“不建议合并”。 |
| S6：10,000 条扫描 | E2E 使用固定种子运行 10,000 条质量批次扫描，并断言耗时小于 300 秒。 |
| S7：问责可答 | E2E 断言问责响应包含审批快照与关联 trace；API 合同测试覆盖模型版本、输入摘要与证据引用。 |

## 演示边界

- 归并执行端只完成批准门禁与执行预检，真实主数据归并由外部执行器承担。
- DeepSeek 真实通道不作为现场依赖；默认 mock 模式保证演示可重复。
- 当前单机演示同步扫描上限为 5,000 条，超过该范围应按批次运行（超限直接拒绝，不自动切批）。
