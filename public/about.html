🏭 制造业数据治理平台

物料主数据全生命周期管理系统

📋 项目概述

本平台是一个面向制造业的物料主数据治理系统（MDM）， 实现了从物料申请、校验、去重、编码、审批到发布的端到端治理闭环。

核心目标是建立以 Golden Record（金标数据） 为权威数据源， 以业务规则和审批为保障，以 ERP/BTP 为执行出口的主数据治理体系。

🎯 核心功能

📝 物料申请管理

支持物料申请的创建、编辑、保存草稿、提交，包含附件上传（图纸、规格书等）

✅ 数据质量校验

自动校验必填字段、名称长度、分类有效性、属性模板，确保数据质量

🔍 重复物料识别

基于 ILIKE + 前缀模糊匹配算法，自动检测重复物料，避免数据冗余

🔢 智能编码生成

基于编码规则自动生成物料编码，使用 UPDATE...RETURNING 保证并发安全

👥 多级审批流程

支持管理员审批、部门审批两级审批，严格的权限控制和状态机管理

💎 Golden Record

权威主数据记录，支持版本管理、修订、失效、回滚，确保数据一致性

📊 分类与模板

三级物料分类树（大类→中类→小类），支持属性模板自定义

🔗 外部系统集成

支持 BTP/ERP 发布、OpenMetadata 元数据同步，实现数据流转

📜 审计追踪

全生命周期操作日志，记录每个步骤的执行者、时间、状态和详情

在制造业中，物料主数据需要在多个系统间同步。本系统通过 SAP BTP 实现与 ERP、采购等系统的集成。

📦 SAP BTP（业务技术平台）

SAP Business Technology Platform 是 SAP 提供的云端业务平台，用于连接和集成各种业务系统。

BTP 平台能力

✅ Integration Suite（集成套件）：系统间数据同步

✅ API Management：统一 API 管理

✅ Event Mesh：实时事件驱动

✅ Cloud Connector：安全连接本地系统

✅ AI 服务：智能数据处理

🔄 CPI（云集成）

Cloud Platform Integration 是 BTP 的核心组件，负责系统间的数据同步和转换。

示例：物料主数据发布后，CPI 自动同步到 S/4HANA（ERP）、Ariba（采购）、MES（生产）等系统

🎯 为什么需要 BTP/CPI？

  • 数据一致性：确保所有系统使用相同的物料主数据
  • 自动化同步：避免人工重复录入，减少错误
  • 实时性：物料变更实时通知所有相关系统
  • 可追溯：记录数据同步历史，便于审计

💡 本项目中的实现

当前项目使用 Mock 实现模拟 BTP/CPI 集成，演示数据同步流程：

  • 发布金标数据时，模拟调用 BTP API
  • 返回同步 ID（如 BTP-20260713-1234）和目标系统列表
  • 支持同步失败重试和补偿

生产环境中，需要配置真实的 SAP BTP 租户和 CPI 集成流。

🔐 安全特性

  • JWT 认证：所有 API 必须携带有效 JWT，无免认证回退
  • 密钥管理：生产环境强制 MDM_SECRET_KEY 环境变量，缺失即 fail-fast
  • 附件安全：类型黑名单（HTML/SVG/JS）+ 10MB 流式大小限制
  • 下载防护：强制 application/octet-stream + Content-Disposition: attachment，防存储型 XSS
  • 并发安全：编码生成使用单语句 UPDATE...RETURNING，消除竞态
  • 越权控制：严格的角色权限校验，普通用户无法执行审批/发布操作
