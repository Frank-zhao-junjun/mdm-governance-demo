🏭 制造业数据治理平台

存量数据治理与数据质量管理平台 · v2.0.0

📋 项目概述

本平台是一个面向制造业的存量数据治理系统（Stock Data Governance）， 针对物料、供应商、客户三类主数据的存量数据，建立 数据标准 → 质量检测 → 疑似错误识别 → AI 辅助裁决 → 问题闭环的完整治理能力。

核心目标是让存量主数据可检测、可裁决、可追溯： 以数据标准为规则来源，以自动化检测为发现手段，以 AI Agent 为建议引擎，以人工裁决为最终关口， 全程留痕、可审计。

🚧 服务边界

平台职能边界清晰：只提供数据治理与数据质量管理服务，不承接业务流程。

✅ 本平台负责

  • 数据标准管理（业务 / 数据 / 管理三类属性）
  • 存量数据质量检测（批次 + 失败明细 + 报告）
  • 疑似错误识别（重复、不规范、异常）
  • AI 辅助建议与 Copilot 人工裁决
  • 治理工单闭环、审计追踪、证据链

🚫 本平台不负责

  • 新增数据申请与业务审批流程
  • Golden Data（金标数据）管理
  • 下游分发执行（ERP/BTP 发布）
  • 数据自动修复（只检测、报告、给建议）

归并执行只输出建议与执行预检： merge-execute 在校验批准状态后仅返回 ready， 实际归并由外部执行器承担，平台不改写业务记录。

🎯 核心功能

📐 数据标准管理

按业务属性、数据属性、管理属性三类维度定义字段标准：命名规范、值域范围、必填规则、编码模式，标准即规则来源

✅ 数据质量检测

标准自动派生检测规则（必填→空值、模式→格式等），人工触发批量检测，批次 + 失败明细持久化，支持质量报告

🔍 疑似错误识别

识别重复、不规范、异常数据；三键去重防重复上报，误报白名单与终态拦截，人工确认处理

🧬 重复识别与归并建议

中文感知分词 + 词元重叠度算法识别重复簇，输出归并建议；平台只出建议和预检，绝不直接合并业务记录

⚖️ Copilot 裁决

所有 AI 建议均需责任人裁决：批准 / 驳回 / 改判；高风险归并强制意见填写 + 二次确认 + 审批前证据快照

🤖 Agent 编排

StandardAgent / QualityAgent / DedupAgent 分工协作，编排器按 request_id 幂等、进程内锁串行化，全程 trace 可审计

📊 治理驾驶舱

质量得分、重复率、待办裁决、Agent 活动流一屏总览，治理 Owner 权责清晰

📥 CSV 批量导入

存量数据通过 CSV upsert 导入，单批上限 5,000 行，超限拒绝并要求分批

📜 审计追踪

审计日志 + Agent trace + 审批证据快照三层留痕，每个裁决可回溯到依据与执行者

🧠 AI 辅助治理层

AI 治理链：LLM 网关 → Agent（trace 可审计）→ Skill（确定性、无副作用）→ 工单 → 人工裁决。

层职责硬约束
LLM 网关统一调用入口，mock / DeepSeek 两种模式15s 超时 + 熔断 + 自动降级回确定性结果，治理能力不依赖外部 LLM 可用性
Agent标准建议、质量工单指派（3 天 SLA）、归并建议工单只出建议，不直接改写存量记录；失败可审计返回
Skill命名 / 属性 / 单位 / 质量规则 / 重复匹配的确定性判定无副作用、禁止写库；与 LLM 输出冲突时以 Skill 为准（L1 覆盖 L3）
工单 + 裁决quality_ticket / merge_ticket 承载建议，Copilot 人工处置高风险归并批准须意见 + 二次确认，留存 approval_evidence 快照

🔐 安全与工程约束

  • JWT 认证：所有 API 必须携带有效 JWT，无免认证回退
  • 密钥管理：生产环境强制 MDM_SECRET_KEY 环境变量，缺失即 fail-fast
  • 归并门禁：merge-execute 仅 admin / data_admin 可调用，未批准返回 409，批准后只返回 ready
  • 审批快照：高风险归并批准必须填写意见且二次确认，裁决前 status / evidence / trace 快照存档
  • Skill 无副作用：Skill 层只输出建议，禁止写库
  • 编排幂等：按 request_id 检查已有工单，重复提交不产生重复工单
  • 批量上限：实体批量操作上限 5,000，五处口径一致，超限拒绝不自动切批

🚀 项目亮点

  • 边界清晰：只做治理与质量，不越界承接业务流程，职责经得起架构评审
  • 人机分工明确：AI 出建议、人做裁决，高风险动作强制意见 + 二次确认 + 快照
  • 确定性优先：Skill 规则判定覆盖 LLM 不确定性输出，LLM 熔断降级不影响治理能力
  • 全程可审计：审计日志 + Agent trace + 审批证据三层留痕
  • 工程质量：后端 310 个 pytest 用例，CI 双 job（前端 lint + tsc + build / 后端 pytest）
